# HMS Bridge v0.1

Huawei Google-services compatibility diagnostics prototype.

**Current scope:** device information scanner and report UI only. It does not install Google packages, root the device, or change system settings.

## Build
Open this folder in Android Studio, sync Gradle, then run the app on an Android device or emulator.

## Planned milestones
- [x] Device scanner and basic report
- [ ] Google-component presence checks
- [ ] Verified compatibility rules
- [ ] Guided setup and diagnostics

Compatibility advice will be based on verified device/firmware rules, not model-name guesses.
